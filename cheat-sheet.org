#+title: Emacs Shortcuts Cheat Sheet
#+subtitle: Built-in Emacs + this config (init.el) + extras/
#+options: toc:2 num:nil

This sheet covers (1) essential *built-in* GNU Emacs keys, (2) every binding
defined in =init.el=, and (3) language extras under =extras/=. Meow normal-state
keys replace many motion/edit defaults while INSERT keeps vanilla Emacs editing.

Discover anything live: =C-h b= (buffer bindings), =C-h k= (describe key),
=C-h w= (where-is), =C-h m= (mode help), =C-h B= (embark-bindings, searchable).

** Keyboard conventions (built-in)
- =C-= Control, =M-= Meta/Alt, =S-= Shift, =s-= Super/Win
- =C-x= global prefix (files, windows, registers…)
- =C-c= reserved for major/minor modes and user keys
- =C-h= help prefix
- =M-x= run any command by name
- Full dump of *all* active keys: =C-h b= or =C-h B= (embark)
